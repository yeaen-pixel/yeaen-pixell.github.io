# 🔐 암호화 비밀 일기장

하루의 감정을 표현할 수 있는 나만의 비밀 일기장 웹 애플리케이션입니다.

## 📘 프로젝트 개요

**프로젝트명:** 암호화 비밀 일기장  
**기술 스택:** HTML, CSS, JavaScript (프론트엔드만 사용, 백엔드 없음)  
**저장 방식:** LocalStorage (클라이언트 측 저장)  
**암호화 방식:** 비밀번호 기반 XOR 암호화 + Base64 인코딩

### 요약
사용자가 일기를 작성하고 비밀번호를 입력하면, 내용이 암호화되어 **브라우저의 LocalStorage**에 저장되는 웹 앱입니다.  
저장된 일기를 다시 열 때는 같은 비밀번호를 입력해야 복호화됩니다.  
비밀번호가 틀리면 "암호가 틀립니다." 라는 오류 메시지를 표시합니다.

---

## 🎯 주요 기능

### 1️⃣ 일기 작성 및 저장
- 날짜별 일기 작성 및 저장
- 비밀번호 기반 암호화 저장
- 제목 편집 기능
- 암호화된 데이터만 LocalStorage에 저장
- 원문(평문)은 절대 저장하지 않음

### 2️⃣ 일기 불러오기 (복호화)
- 저장된 일기를 비밀번호로 복호화하여 불러오기
- 비밀번호 해시 검증을 통한 보안 강화
- 비밀번호 오류 시 명확한 오류 메시지 표시
- 복호화 성공 시 성공 메시지 표시

### 3️⃣ 캘린더 기능
- 월별 캘린더 뷰
- 날짜별 일기 조회
- 지난 날짜 연하게 표시
- 날짜 클릭 시 해당 날짜의 일기 작성/조회

### 4️⃣ 감정 캘린더
- 날짜별 기분을 이모지로 표현
- 8가지 기분 이모지 선택
- 선택한 기분이 일기 카드에 표시

### 5️⃣ 전체 삭제
- 모든 일기와 비밀번호 영구 삭제
- 감정 데이터 삭제
- 확인 다이얼로그를 통한 실수 방지
- 삭제 후 메인 화면으로 자동 이동

## 🎨 UI 구성 요소 

### 메인 화면
- **헤더**: 더보기 메뉴(☰), 현재 시간, 날짜 표시
- **캘린더 영역**: 월별 캘린더 그리드, 요일 표시, 날짜 클릭 가능
- **일기 미리보기 카드**: 선택한 날짜의 일기 정보, 잠금 상태 표시

### 일기 작성 화면
- **제목 입력 필드**: 편집 가능한 제목 입력
- **날짜 표시**: 선택한 날짜 정보 표시
- **비밀번호 입력**: 비밀번호 입력 필드 및 해제 버튼
- **일기 작성 영역**: 텍스트 입력 textarea (기본 잠금 상태)
- **액션 버튼**: 저장(💾), 초기화(🔄) 버튼
- **전체 삭제 버튼**: 모든 일기와 비밀번호 삭제(🗑️)
- **상태 메시지**: 성공/오류 메시지 표시 영역

### 감정 캘린더 화면
- **월별 네비게이션**: 이전/다음 월 이동 버튼
- **감정 캘린더 그리드**: 날짜별 기분 선택 가능한 캘린더
- **기분 선택 모달**: 8가지 이모지 기분 선택 옵션

### 더보기 메뉴
- **모달 창**: 파스텔톤 그라데이션 배경
- **메뉴 옵션**: 
  - 웃는 이모지(😊): 감정 캘린더 이동
  - 연필 이모지(✏️): 메인 화면 이동

## 🚀 시작하기

### 설치 방법

1. 프로젝트 파일을 다운로드하거나 클론합니다.
2. `index.html` 파일을 웹 브라우저에서 엽니다.
3. 바로 사용할 수 있습니다!

### 파일 구조

```
secret-diary/
├── index.html      # 메인 HTML 파일
├── style.css       # 스타일시트
├── script.js       # JavaScript 로직
└── README.md       # 프로젝트 설명서
```

## 💻 사용 방법

### 일기 작성하기

1. 메인 화면에서 날짜를 클릭합니다.
2. 비밀번호를 입력하고 "🔓 해제" 버튼을 클릭합니다.
3. 일기 내용을 작성합니다.
4. 제목을 원하는 대로 변경할 수 있습니다.
5. "저장" 버튼을 클릭하여 저장합니다.

### 일기 불러오기

1. 메인 화면에서 날짜를 클릭합니다.
2. 저장 시 사용한 비밀번호를 입력합니다.
3. "🔓 해제" 버튼을 클릭합니다.
4. 비밀번호가 맞으면 일기 내용이 표시됩니다.

### 감정 선택하기

1. 더보기 메뉴(☰)를 클릭합니다.
2. 웃는 이모지(😊)를 클릭하여 감정 캘린더로 이동합니다.
3. 날짜를 선택하고 기분 이모지를 선택합니다.
4. 선택한 기분은 일기 카드에 표시됩니다.

### 전체 삭제하기

1. 일기 작성 화면에서 "🗑️ 전체 삭제" 버튼을 클릭합니다.
2. 확인 다이얼로그에서 다시 확인합니다.
3. 모든 일기, 비밀번호, 감정 데이터가 영구적으로 삭제됩니다.
4. 삭제 후 메인 화면으로 자동 이동합니다.

**⚠️ 주의**: 전체 삭제는 되돌릴 수 없습니다!

## 🔐 보안 기능

- **비밀번호 해시 검증**: SHA-256 해시를 사용한 비밀번호 검증
- **암호화 저장**: XOR 암호화 + Base64 인코딩
- **로컬 저장**: 모든 데이터는 사용자의 브라우저에만 저장
- **평문 미저장**: 암호화된 데이터만 저장, 원문은 저장하지 않음

- **반응형 디자인**: 다양한 화면 크기에 대응

## 📝 주요 기능 상세

### 암호화/복호화
- 비밀번호 기반 XOR 연산
- TextEncoder/TextDecoder를 통한 UTF-8 지원
- Base64 인코딩을 통한 문자열 변환
- SHA-256 해시를 통한 비밀번호 검증

### 데이터 저장 구조
```json
{
  "dates": {
    "2025-11-02": {
      "encryptedDiary": "암호화된_데이터",
      "passwordHash": "비밀번호_해시",
      "lastSaved": "2025-11-02T12:00:00",
      "title": "일기 제목",
      "preview": "일기 미리보기"
    }
  },
  "moods": {
    "2025-11-02": "😊"
  }
}
```

## ⚠️ 주의사항

- 모든 데이터는 브라우저의 LocalStorage에 저장됩니다.
- 브라우저 캐시를 삭제하면 저장된 일기가 사라질 수 있습니다.
- 다른 컴퓨터나 브라우저에서는 저장된 일기를 볼 수 없습니다.
- 비밀번호를 잊어버리면 일기를 복호화할 수 없습니다.
